# Lexical and Syntactic Language Parser in Python

Academic project developed for the **Formal Languages and Programming** course at the Universidad de San Carlos de Guatemala (First Semester 2024).

This repository contains a compiler front-end featuring a deterministic finite automaton (DFA) based lexical analyzer and a top-down syntactic parser written entirely from scratch in Python.

---

## Overview

The engine analyzes custom `.lfp` domain-specific configuration files. It processes raw character streams, classifies tokens, detects and logs lexical errors, performs syntactic verification against a formal grammar, and builds an internal representation for data extraction and reporting.

---

## Key Features

- Lexical scanner driven by transition tables and pattern matching
- Syntactic analyzer enforcing language grammar rules
- Detailed error logging table (lexical and grammatical errors with line and column numbers)
- HTML report generation for visual verification of tokens and errors

---

## Technologies

- **Language:** Python 3
- **Reports:** HTML5, CSS
